# Vinicius Tech Labs

Portfólio técnico em construção, dedicado ao registro de estudos e práticas reais em tecnologia. O repositório documenta conceitos estudados, laboratórios realizados, problemas encontrados e as soluções aplicadas.

## Áreas em estudo

- Linux
- Networking & Infrastructure (Cisco)
- Cybersecurity *(quando começar)*
- Python *(quando começar)*
- Databases *(quando começar)*

## Estrutura

```text
vinicius-tech-labs/
├── README.md
├── LICENSE
├── .gitignore
├── linux/
│   ├── studies/
│   └── labs/
└── networking/
    └── cisco/
        ├── studies/
        └── labs/
```

As áreas de Cybersecurity, Python, Databases e a pasta `projects/` serão criadas somente quando houver conteúdo real para documentar.

## Princípios

- Documentar somente o que foi realmente estudado ou praticado.
- Registrar erros e dificuldades como parte da evolução.
- Diferenciar estudo teórico (`studies/`) de laboratório prático (`labs/`).
- Usar arquivos prefixados com a data (`aaaa-mm-dd-...`) para preservar a ordem dos registros.
- Expandir a estrutura somente quando novos conteúdos surgirem.

## Status

Portfólio em reorganização. Atualmente, o repositório contém uma nota de estudo sobre Modelo OSI, ARP, endereçamento IPv4, máscaras de sub-rede e subnetting em `networking/cisco/studies/`.

Transformar o conteúdo em um site próprio, construído em HTML, CSS e JavaScript puros, e avaliar a integração entre o repositório e a apresentação web quando esse projeto existir.
