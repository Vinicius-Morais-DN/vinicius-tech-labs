# Vinicius Tech Labs

Repositório de estudos, laboratórios e evolução prática em tecnologia.

O projeto acompanha minha evolução cronológica em Linux, Redes e Cisco.
Novos assuntos, laboratórios e áreas serão adicionados conforme forem
realmente estudados e praticados.

## Estrutura

- `timeline/` — linha cronológica da evolução
- `linux/studies/` — estudos e resumos de Linux
- `linux/labs/` — laboratórios práticos de Linux
- `networking/cisco/studies/` — estudos de Redes/Cisco
- `networking/cisco/labs/` — laboratórios práticos de Redes/Cisco
- `docs/` — metodologia e roadmap do projeto
- `images/` — imagens compartilhadas quando necessário
- `.github/` — automações e templates futuros

## Princípios

- Documentar somente o que foi realmente estudado ou praticado.
- Registrar erros e dificuldades como parte da evolução.
- Usar datas para preservar a linha do tempo.
- Diferenciar estudo teórico de laboratório prático.
- Expandir a estrutura somente quando novos conteúdos surgirem.

## Status

Projeto iniciado em 2026.
