# RELATÓRIO — INTRODUÇÃO A BANCO DE DADOS E SQL

## 1. Introdução

O vídeo apresentou conceitos básicos sobre banco de dados, sua estrutura, os sistemas responsáveis pelo seu gerenciamento e a linguagem SQL. O conteúdo também mostrou como os modelos de banco de dados evoluíram até chegar ao modelo relacional, utilizado pelo MySQL.

## 2. Estrutura dos dados

Um dos conceitos apresentados foi a forma como os dados podem ser organizados. Os arquivos podem armazenar tabelas, enquanto as tabelas armazenam registros, que representam as informações cadastradas.

Essa organização permite que os dados sejam armazenados de maneira estruturada, facilitando sua consulta e seu gerenciamento.

## 3. Componentes de um banco de dados

O conteúdo apresentou que um sistema de banco de dados envolve diferentes componentes. Entre eles estão:

- **Base de dados:** onde ficam organizadas as informações.
- **Sistema Gerenciador de Banco de Dados (SGBD):** responsável pelo gerenciamento e controle dos dados.
- **Linguagem de exploração:** utilizada para consultar e manipular as informações armazenadas.
- **Programas adicionais:** ferramentas que auxiliam no funcionamento e gerenciamento do banco de dados.

O SGBD é importante porque permite controlar o acesso e trabalhar com os dados de forma organizada.

## 4. Modelos de banco de dados

O vídeo apresentou diferentes modelos utilizados para organizar os dados. Entre eles estão o **modelo hierárquico**, o **modelo em redes** e o **modelo relacional**.

O **modelo hierárquico** organiza os dados seguindo uma estrutura semelhante a uma árvore, estabelecendo uma relação entre elementos principais e seus elementos dependentes.

O **modelo em redes** surgiu como uma evolução do modelo hierárquico, permitindo relações mais flexíveis entre os dados. Nesse modelo, um registro pode possuir relações com diferentes registros.

Já o **modelo relacional** organiza as informações em tabelas e permite estabelecer relações entre elas. Esse é o modelo utilizado pelo **MySQL**. Por meio dos relacionamentos entre as tabelas, é possível consultar e acessar informações que estão relacionadas, sem precisar manter todos os dados em uma única tabela.

## 5. SQL

SQL é uma linguagem utilizada para consultar e manipular bancos de dados. A ideia inicial era que ela pudesse funcionar como uma linguagem universal para trabalhar com diferentes sistemas de banco de dados.

Porém, diferentes fabricantes implementaram suas próprias versões e características da linguagem. Isso acabou criando algumas diferenças entre os sistemas e pode causar dificuldades quando um código desenvolvido para um banco de dados precisa ser utilizado em outro.

Entre os sistemas e fabricantes apresentados no conteúdo estão **Oracle, IBM, dBase e SQL Server, da Microsoft**, além do **MySQL**, que é uma das opções utilizadas para trabalhar com bancos de dados relacionais.

## 6. O que compreendi

O que mais compreendi com o vídeo foi que um banco de dados não é apenas um local onde informações ficam armazenadas. Existe toda uma estrutura responsável por organizar, controlar e permitir o acesso aos dados.

Também compreendi que existem diferentes modelos de organização dos bancos de dados e que o modelo relacional utiliza tabelas que podem possuir relações entre si. Esse conceito é importante para entender o funcionamento do MySQL e posteriormente aprender a utilizar SQL para consultar e modificar os dados.
