# Imagens do portfólio

As imagens desta pasta são usadas como base visual para a primeira versão do site. Antes de usar o portfólio em divulgação comercial, confirme a licença de cada imagem ou substitua os arquivos por fotos próprias, imagens do seu laboratório ou assets com licença aberta.

## Arquivos

- `network-rack.jpg`: imagem principal da seção hero.
- `server-room.jpg`: imagem do card de estudo de redes.
- `server-detail.jpg`: imagem do card do laboratório Packet Tracer.

Para trocar uma imagem, mantenha o mesmo nome de arquivo ou atualize o atributo `src` correspondente no `index.html`.
